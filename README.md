# Password Generator

My first personal public Python project.

A simple terminal-based password generator. You choose the length and whether to include numbers/symbols, and it generates a random password for you.

## How to run
python Password_Generator.py

## What I learned
- Working with user input
- Using loops and conditionals
- Random character generation with Python's random module

## Example
Enter password length: 12
Include symbols? (y/n): y
Include numbers? (y/n): y
Generated: xT9!qR2$vLmZ
