# Password Generator

My first personal public Python project.

A terminal-based password manager. Generate random passwords with custom length and options (numbers/symbols), save them by site and username, and search back through saved passwords later.

## Features
- Generate a random password with custom length
- Choose to include numbers and/or symbols
- Save generated passwords to a file (site, username, password)
- Search saved passwords by site name
- List all saved passwords at once

## How to run
python Password_Generator.py

## How to use
- Enter G to generate a new password
- Enter L to search or list saved passwords

## What I learned
- Working with user input and menus
- Using loops and conditionals
- Random character generation with Python's random module
- Reading and writing to files
- Basic search logic
